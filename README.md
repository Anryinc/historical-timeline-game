# ⏳ Historical Timeline Challenge

Браузерная игра: расставь известные исторические события на временной шкале.

## Играть

**[▶ Запустить игру](https://anryinc.github.io/historical-timeline-game/)**

(После включения GitHub Pages в настройках репозитория: Settings → Pages → Source: Deploy from a branch → main / (root))

## Как играть

1. Выбери сложность (15 / 30 / 60 событий).
2. На шкале стоит только **0** — рождение Христа.
3. Тебе дают события по одному. Размести каждое **между** уже существующими метками (клик по промежутку или drag-and-drop).
4. Если год события действительно находится между соседями — оно закрепляется. Иначе — сгорает.
5. Чем больше правильных событий, тем уже промежутки.

## Особенности

- База ~100 мировых исторических событий (с метками эпох и категорий)
- Анализ сильных/слабых сторон по эпохам и темам
- Настройки: показывать годы / разрешать события одного года
- Красивый экран победы с очками и процентом точности
- Кнопки «На главную» и «Реванш»
- Полностью статическая — работает на GitHub Pages
- Адаптив под мобильные

## Локальный запуск

Просто открой `index.html` в браузере или:

```bash
npx serve .
```

## Технологии

- Vanilla JS
- CSS (без фреймворков)
- JSON база событий
