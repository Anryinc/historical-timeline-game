Картинки подсказок
====================

Каждое событие в events.json (в корне сайта) ссылается на один файл:

  "id": "industrial-start",
  "image": "images/industrial-start.jpg"

Имя файла = id события + расширение.

Как заменить картинку
---------------------
1. Открой gallery.html — там название события и точное имя файла.
2. Замени файл в этой папке, сохранив то же имя (например industrial-start.jpg).
3. Если меняешь расширение, поправь поле image в events.json.
4. Обнови игру жёстким обновлением: Ctrl+Shift+R.

Живой поиск по Википедии в подсказках не используется: показывается только этот файл.
catalog.json — та же привязка (id, название, файл) для удобства.
